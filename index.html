Why?

  • Autofixable

    Nearly every rule fixes what it reports, so one run of stylelint --fix brings a stylesheet to the convention.

    See the rules

  • Recommended config

    A preset consisting of carefully selected values from the entire set of rules ensures attractive formatting of style sheets.

    Configs

  • Typed configuration

    A JavaScript configuration names the rules by their short names, and the editor completes and checks every name and option.
