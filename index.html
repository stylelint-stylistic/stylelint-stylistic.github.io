Why?

  • Autofixable

    Nearly every rule fixes what it reports, so one run of stylelint --fix brings a stylesheet to the convention.

    See the rules

  • CSS, SCSS, Less and styled templates

    The core reads plain CSS. A stylesheet in SCSS or Less, or a styled template, is read by the same rules under a namespace of its own.

    Custom syntaxes

  • Typed configuration

    A JavaScript configuration names the rules by their short names, and the editor completes and checks every name and option.

    Typed configuration
